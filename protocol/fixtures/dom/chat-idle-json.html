Sure! Here's a simple JSON example in a code block:

JSON
{
"name": "Alice",
"age": 30,
"email": "alice@example.com",
"isMember": true,
"interests": [
"reading",
"cycling",
"photography"
],
"address": {
"city": "Canberra",
"country": "Australia"
}
}

A few JSON basics:

  • Objects use {}.
  • Arrays use [].
  • Keys and string values use double quotes ".
  • JSON supports strings, numbers, booleans (true/false), arrays, objects, and null.
